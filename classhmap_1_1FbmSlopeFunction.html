Detailed Description

template<typename BaseFn>
class hmap::FbmSlopeFunction< BaseFn >

Slope-weighted FBM layering function class.

Modulates higher-octave amplitude by the accumulated low-frequency gradient norm so that flat areas remain smooth while steep slopes develop rugosity.
