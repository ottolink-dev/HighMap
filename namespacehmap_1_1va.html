Parameters
cmCompute mode configuration.
zInput elevation VirtualArray.
control_points_countNumber of mesh control vertices sampled.
seedRandom seed for vertex distribution.
riverbed_talusMinimum talus (slope) along carved riverbeds.
elevation_ratioWeight for absolute elevation in Dijkstra step cost.
distance_exponentExponent applied to upward elevation changes.
upward_penalizationPenalty factor for uphill moves.
minimum_depthMinimum incision depth below terrain elevation.
merging_distanceTrench width in pixels.
radial_profileRadial profile cross-section for trench carving.
radial_profile_parameterParameter for radial profile shaping.
p_noise_rOptional noise VirtualArray for radial trench perturbation.
Returns
Carved elevation VirtualArray with unbroken flow paths.
