◆ densify()

void hmap::Forest::densify ( float  default_radius = HMAP_DEFAULT_TREE_RADIUS)

Densifies the forest by adding Voronoi vertices (circumcenters of Delaunay triangles).

Computes the Delaunay triangulation of the existing trees. For each triangle, computes its circumcenter (a Voronoi vertex) and inserts a new tree with the majority species identifier among the triangle's 3 vertices and the specified default radius.

Parameters
default_radiusDefault radius assigned to newly added trees.

◆ prune_unviable()

void hmap::Forest::prune_unviable ( const std::vector< Species > &  species = {},
bool  prune_collisions = true 
)

Prunes unviable trees whose distance to their nearest neighbor is insufficient to meet their species' minimum radius requirement or pairwise collision distance.

Uses a KD-Tree / nearest-neighbor search to find the distance $d_{nn}$ to the closest neighbor. If estimated radius $\alpha \cdot d_{nn} < r_{\min}$ (or if overlapping with a larger tree), the tree is pruned.

Parameters
speciesVector of species definitions (with radius_min, radius_max, competition_factor).
prune_collisionsIf true, also resolves overlapping tree crowns by discarding the smaller tree.

Randomly shuffles species identifiers between neighboring trees.

For a randomly selected ratio of trees, a tree swaps its species with one of its k_neighbors. If all neighbors have the same species as the candidate node, no swap is made.

Parameters
ratioFraction of trees to attempt species shuffling on in [0, 1].
k_neighborsNumber of nearest spatial neighbors to consider.
seedRandom seed for reproducibility.

Array hmap::Forest::to_density_map ( glm::ivec2  shape,
float  sigma = 0.0f,
std::optional< uint32_t >  species_id = std::nullopt,
bool  weighted_by_crown = false,
glm::vec4  bbox = {0.f, 1.f, 0.f, 1.f}

Exports the local density map of the forest as a 2D Array using 2D Kernel Density Estimation (Gaussian splatting / KDE).

Splats each tree into the regular grid and accumulates smooth 2D Gaussian kernels with bandwidth sigma. If weighted_by_crown is true, each contribution is weighted by the tree crown surface ($\pi r^2$) instead of unit count.

Parameters
shapeDimensions of the output density map {nx, ny}.
sigmaGaussian kernel standard deviation (bandwidth) in world/domain coordinates. If <= 0, automatically derived from the bounding box and grid shape.
species_idOptional species identifier to compute density for a specific species only.
weighted_by_crownIf true, weights tree density by crown surface ($\pi r^2$).
bboxBounding box defining the domain {xmin, xmax, ymin, ymax}.
Returns
Array 2D continuous density map array.
