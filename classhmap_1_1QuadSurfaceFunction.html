Detailed Description

Quadratic surface function defined by four corner values.

This class interpolates a surface across the bounding box domain using bilinear/quadratic interpolation from four corner elevations: c00 (bottom-left), c10 (bottom-right), c01 (top-left), and c11 (top-right).
