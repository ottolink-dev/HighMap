\doxysubsection{Detailed Description}
A class for generating noise functions. 

The {\ttfamily \doxylink{classhmap_1_1NoiseFunction}{Noise\+Function}} class provides an interface for generating noise-\/based functions. It inherits from the {\ttfamily Function} class and adds parameters for frequency scaling ({\ttfamily \doxylink{classhmap_1_1NoiseFunction_a332703b9642cf219cb6d6e91488648cf}{kw}}) and a random seed ({\ttfamily \doxylink{classhmap_1_1NoiseFunction_afcc0d96413b1b200fc0ec671e43dcbc3}{seed}}) to customize the noise generation.
