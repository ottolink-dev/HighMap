\doxysubsection{Detailed Description}
Per-\/vertex penalty term used by \doxylink{namespacehmap_abec90e80c5d42318a7aadf6dd1016fec}{sls\+\_\+deformation}. 

Each constraint contributes {\ttfamily scale \texorpdfstring{$\ast$}{*} \doxylink{structhmap_1_1DeformationConstraint_af0e2e25f46be9570214dcfa57bc83083}{weight(x, y)} \texorpdfstring{$\ast$}{*} (\doxylink{hydraulic__mise_8cpp_aa14e04bff7de9e968e46a953f71f29f3}{z(x, y)} -\/ \doxylink{structhmap_1_1DeformationConstraint_a8f3ae7134e1a09cedb0f8e67a5a0040b}{target(x, y)})\texorpdfstring{$^\wedge$}{\string^}2} to the fitness of a vertex, gated by its type\+: for {\ttfamily MATCH} the penalty always applies, for {\ttfamily ABOVE} only where {\ttfamily z \texorpdfstring{$<$}{<} target}, for {\ttfamily BELOW} only where {\ttfamily z \texorpdfstring{$>$}{>} target}. Vertices with a zero weight are unconstrained by that term. Several constraints are summed, so the {\ttfamily scale} factor can be used to normalize competing terms.

Typical uses (after Stachniak \& Stuerzlinger, 2005)\+:
\begin{DoxyItemize}
\item match a reference height map\+: {\ttfamily target = ref, weight = 1, MATCH};
\item shape mask (island)\+: {\ttfamily target = water\+\_\+level, weight = mask, ABOVE} plus {\ttfamily target = water\+\_\+level, weight = 1 -\/ mask, BELOW};
\item flat road\+: {\ttfamily target = road\+\_\+height, weight = path, MATCH} plus {\ttfamily target = original, weight = 1 -\/ path, MATCH} (preserve the rest);
\item edge matching\+: {\ttfamily target} = neighbour terrain edge values, {\ttfamily weight} non-\/zero along the edge only, {\ttfamily MATCH}. 
\end{DoxyItemize}
