 High\+Map is a C++ library for procedural generation, simulation, and analysis of 2D heightmaps and terrain assets.

A heightmap is a two-\/dimensional grid of elevation values. Each cell corresponds to a spatial position, with values typically normalized to \$\mbox{[}0, 1\mbox{]}\$ or expressed in world elevation units.
