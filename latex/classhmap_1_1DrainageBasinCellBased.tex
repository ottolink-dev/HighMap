\doxysubsection{Detailed Description}
Represents a cell-\/based hydrology drainage basin network on a 2D heightmap grid. 

This class implements hydrological flow network computations (receivers, outlets, main channels, upstream traversals) on a regular grid represented by a 2D \doxylink{classhmap_1_1Array}{Array}.
