\doxysubsection{Detailed Description}
Header file for 2D image and raster export functionalities. 

\begin{DoxyAuthor}{Author}
Otto Link (\href{mailto:otto.link.bv@gmail.com}{\texttt{ otto.\+link.\+bv@gmail.\+com}}) 
\end{DoxyAuthor}
This header declares functions for exporting heightmaps and arrays to image formats (PNG, cubemaps, banners, splatmaps, tiled textures, ASCII art) and reading raster images into arrays.
