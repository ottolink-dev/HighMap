\doxysubsection{Detailed Description}
A class to represent a multi-\/channel texture using planar \doxylink{classhmap_1_1Array}{hmap\+::\+Array} storage. 

The {\ttfamily \doxylink{classhmap_1_1Texture}{Texture}} class represents a multi-\/channel image/texture. Each channel is stored as a separate {\ttfamily \doxylink{classhmap_1_1Array}{Array}} object, allowing direct use of {\ttfamily \doxylink{classhmap_1_1Array}{Array}} functions and operators on individual channels without copying. \begin{Desc}
