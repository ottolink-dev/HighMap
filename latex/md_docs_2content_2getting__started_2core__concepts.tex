\begin{DoxyItemize}
\item {\ttfamily \doxylink{classhmap_1_1NoiseFunction}{hmap\+::\+Noise\+Function}}\+: Perlin, Simplex, and cellular noise generators.
\item {\ttfamily \doxylink{classhmap_1_1FbmFunction}{hmap\+::\+Fbm\+Function}}\+: Multi-\/octave fractal noise.
\item {\ttfamily \doxylink{classhmap_1_1FieldFunction}{hmap\+::\+Field\+Function}}\+: Distance fields and geometric functions.

\begin{DoxyItemize}
\item {\ttfamily \doxylink{classhmap_1_1Point}{hmap\+::\+Point}} / {\ttfamily \doxylink{classhmap_1_1Cloud}{hmap\+::\+Cloud}}\+: Individual points and point clouds.
\item {\ttfamily \doxylink{structhmap_1_1Edge}{hmap\+::\+Edge}} / {\ttfamily \doxylink{classhmap_1_1Path}{hmap\+::\+Path}}\+: Segments and ordered sequences of points.

\begin{DoxyItemize}

\item {\ttfamily \doxylink{classhmap_1_1Forest}{hmap\+::\+Forest}}\+: Scattering container for vegetation and growth models.
\item {\ttfamily \doxylink{classhmap_1_1RockField}{hmap\+::\+Rock\+Field}}\+: Scattering container for rock and debris placement.
