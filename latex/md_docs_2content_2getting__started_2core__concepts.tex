When simulating erosion or analyzing terrain gradients, High\+Map distinguishes between {\bfseries{talus}} and {\bfseries{slope}}\+:\hypertarget{md_docs_2content_2getting__started_2core__concepts_autotoc_md131}{}\doxysubsection{\texorpdfstring{Talus (Grid-\/\+Space Elevation Difference)}{Talus (Grid-\/\+Space Elevation Difference)}}\label{md_docs_2content_2getting__started_2core__concepts_autotoc_md131}
In High\+Map, the {\bfseries{talus}} is defined as the direct elevation difference between neighboring grid cells (or the critical vertical threshold per grid step)\+:

\$\$\textbackslash{}text\{talus\} = \textbackslash{}\+Delta z = z\+\_\+\{i+1, j\} -\/ z\+\_\+\{i, j\}\$\$


\begin{DoxyItemize}
\item {\bfseries{Resolution dependent}}\+: For a given physical terrain gradient, increasing the grid resolution \$\+N\+\_\+x \textbackslash{}times N\+\_\+y\$ places adjacent cell centers closer together, decreasing the elevation step \$\textbackslash{}\+Delta z\$ between neighbors. Consequently, threshold talus parameters scale inversely with grid resolution (e.\+g., \$\textbackslash{}text\{talus\} \textbackslash{}propto 1 / N\+\_\+x\$).
\item {\bfseries{Domain size independent}}\+: Talus operates entirely in discrete grid space (\$i, j\$) and does not depend on the physical world-\/space dimensions of the terrain domain.
\end{DoxyItemize}\hypertarget{md_docs_2content_2getting__started_2core__concepts_autotoc_md132}{}\doxysubsection{\texorpdfstring{Slope (Metric Surface Gradient)}{Slope (Metric Surface Gradient)}}\label{md_docs_2content_2getting__started_2core__concepts_autotoc_md132}
The {\bfseries{slope}} is the metric rate of change of elevation with respect to physical horizontal distance in the terrain domain\+:

\$\$\textbackslash{}text\{slope\} = \textbackslash{}frac\{\textbackslash{}\+Delta z\}\{\textbackslash{}\+Delta x\} = \textbackslash{}frac\{z(\textbackslash{}mathbf\{x\}\+\_\+2) -\/ z(\textbackslash{}mathbf\{x\}\+\_\+1)\}\{$|$\textbackslash{}mathbf\{x\}\+\_\+2 -\/ \textbackslash{}mathbf\{x\}\+\_\+1$|$\}\$\$

where \$\textbackslash{}\+Delta x = L\+\_\+x / N\+\_\+x\$ represents the physical cell spacing for a domain of size \$\+L\+\_\+x\$.


\begin{DoxyItemize}
\item {\bfseries{Domain size dependent}}\+: Slope depends on physical metric units (such as meters or kilometers) and the overall domain extent \$\+L\+\_\+x \textbackslash{}times L\+\_\+y\$.
\item {\bfseries{Resolution independent}}\+: As grid resolution increases (\$\+N\+\_\+x \textbackslash{}to \textbackslash{}infty\$), the ratio \$\textbackslash{}\+Delta z / \textbackslash{}\+Delta x\$ converges toward the continuous spatial derivative \$$|$\textbackslash{}nabla z$|$\$, maintaining an invariant physical slope regardless of raster resolution.
\end{DoxyItemize}\hypertarget{md_docs_2content_2getting__started_2core__concepts_autotoc_md133}{}\doxysubsection{\texorpdfstring{Relationship\+: talus = slope / nx}{Relationship\+: talus = slope / nx}}\label{md_docs_2content_2getting__started_2core__concepts_autotoc_md133}
In unit-\/box normalized domains (\$\+L\+\_\+x = 1\$), the physical cell spacing is \$\textbackslash{}\+Delta x = 1 / N\+\_\+x\$. Substituting \$\textbackslash{}\+Delta x\$ into the slope definition yields\+:

\$\$\textbackslash{}text\{slope\} = \textbackslash{}frac\{\textbackslash{}\+Delta z\}\{\textbackslash{}\+Delta x\} = \textbackslash{}frac\{\textbackslash{}text\{talus\}\}\{1 / N\+\_\+x\} = \textbackslash{}text\{talus\} \textbackslash{}cdot N\+\_\+x\$\$

Rearranging for the grid-\/cell talus threshold gives\+:

\$\$\textbackslash{}text\{talus\} = \textbackslash{}frac\{\textbackslash{}text\{slope\}\}\{N\+\_\+x\}\$\$

This identity is why erosion parameters throughout High\+Map are specified by dividing a reference slope by the grid dimension\+:

\hypertarget{md_docs_2content_2getting__started_2core__concepts_autotoc_md136}{}\doxysubsection{\texorpdfstring{UV ({\ttfamily \mbox{[}0, 1\mbox{]}\texorpdfstring{$^\wedge$}{\string^}2} Normalized Domain)}{UV ({\ttfamily \mbox{[}0, 1\mbox{]}\texorpdfstring{$^\wedge$}{\string^}2} Normalized Domain)}}\label{md_docs_2content_2getting__started_2core__concepts_autotoc_md136}
UV coordinates \$(u, v) \textbackslash{}in \mbox{[}0, 1\mbox{]}\texorpdfstring{$^\wedge$}{\string^}2\$ represent a normalized, resolution-\/independent unit square. {\ttfamily Virtual\+Array} and {\ttfamily Virtual\+Texture} canonically span \$\mbox{[}0, 1\mbox{]}\texorpdfstring{$^\wedge$}{\string^}2\$ in UV space, and each tile carries its own {\ttfamily Uv\+Rect} slice.

\hypertarget{md_docs_2content_2getting__started_2core__concepts_autotoc_md137}{}\doxysubsection{\texorpdfstring{BBox ({\ttfamily BBox2D} Axis-\/\+Aligned Bounding Box)}{BBox ({\ttfamily BBox2D} Axis-\/\+Aligned Bounding Box)}}\label{md_docs_2content_2getting__started_2core__concepts_autotoc_md137}
A bounding box defines an axis-\/aligned rectangular region in world or domain coordinates using {\ttfamily (xmin, xmax, ymin, ymax)}. It is used for spatial extents of geometric primitives ({\ttfamily Cloud}, {\ttfamily Path}, {\ttfamily Graph}), evaluation domains, and fast overlap checks.

\hypertarget{md_docs_2content_2getting__started_2core__concepts_autotoc_md138}{}\doxysubsection{\texorpdfstring{Coord\+Frame ({\ttfamily Coord\+Frame} Oriented Local Frame)}{Coord\+Frame ({\ttfamily Coord\+Frame} Oriented Local Frame)}}\label{md_docs_2content_2getting__started_2core__concepts_autotoc_md138}
{\ttfamily \doxylink{classhmap_1_1CoordFrame}{hmap\+::\+Coord\+Frame}} defines an oriented 2D coordinate frame with an {\ttfamily origin}, {\ttfamily size}, and {\ttfamily rotation\+\_\+angle}. It maps between local unit coordinates \$(r\+\_\+x, r\+\_\+y) \textbackslash{}in \mbox{[}0, 1\mbox{]}\texorpdfstring{$^\wedge$}{\string^}2\$ ({\ttfamily map\+\_\+to\+\_\+global\+\_\+coords}) and global world coordinates \$(g\+\_\+x, g\+\_\+y)\$ ({\ttfamily map\+\_\+to\+\_\+relative\+\_\+coords}), and can compute its enclosing axis-\/aligned bounding box via {\ttfamily compute\+\_\+bounding\+\_\+box()}.
