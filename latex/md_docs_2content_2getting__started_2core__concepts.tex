When simulating erosion or analyzing terrain gradients, High\+Map distinguishes between {\bfseries{talus}} and {\bfseries{slope}}\+:\hypertarget{md_docs_2content_2getting__started_2core__concepts_autotoc_md115}{}\doxysubsection{\texorpdfstring{Talus (\+Grid-\/\+Space Elevation Difference)}{Talus (Grid-Space Elevation Difference)}}\label{md_docs_2content_2getting__started_2core__concepts_autotoc_md115}
In High\+Map, the {\bfseries{talus}} is defined as the direct elevation difference between neighboring grid cells (or the critical vertical threshold per grid step)\+:

\$\$\textbackslash{}text\{talus\} = \textbackslash{}\+Delta z = z\+\_\+\{i+1, j\} -\/ z\+\_\+\{i, j\}\$\$


\begin{DoxyItemize}
\item {\bfseries{Resolution dependent}}\+: For a given physical terrain gradient, increasing the grid resolution \$\+N\+\_\+x \textbackslash{}times N\+\_\+y\$ places adjacent cell centers closer together, decreasing the elevation step \$\textbackslash{}\+Delta z\$ between neighbors. Consequently, threshold talus parameters scale inversely with grid resolution (e.\+g., \$\textbackslash{}text\{talus\} \textbackslash{}propto 1 / N\+\_\+x\$).
\item {\bfseries{Domain size independent}}\+: Talus operates entirely in discrete grid space (\$i, j\$) and does not depend on the physical world-\/space dimensions of the terrain domain.
\end{DoxyItemize}\hypertarget{md_docs_2content_2getting__started_2core__concepts_autotoc_md116}{}\doxysubsection{\texorpdfstring{Slope (\+Metric Surface Gradient)}{Slope (Metric Surface Gradient)}}\label{md_docs_2content_2getting__started_2core__concepts_autotoc_md116}
The {\bfseries{slope}} is the metric rate of change of elevation with respect to physical horizontal distance in the terrain domain\+:

\$\$\textbackslash{}text\{slope\} = \textbackslash{}frac\{\textbackslash{}\+Delta z\}\{\textbackslash{}\+Delta x\} = \textbackslash{}frac\{z(\textbackslash{}mathbf\{x\}\+\_\+2) -\/ z(\textbackslash{}mathbf\{x\}\+\_\+1)\}\{$|$\textbackslash{}mathbf\{x\}\+\_\+2 -\/ \textbackslash{}mathbf\{x\}\+\_\+1$|$\}\$\$

where \$\textbackslash{}\+Delta x = L\+\_\+x / N\+\_\+x\$ represents the physical cell spacing for a domain of size \$\+L\+\_\+x\$.


\begin{DoxyItemize}
\item {\bfseries{Domain size dependent}}\+: Slope depends on physical metric units (such as meters or kilometers) and the overall domain extent \$\+L\+\_\+x \textbackslash{}times L\+\_\+y\$.
\item {\bfseries{Resolution independent}}\+: As grid resolution increases (\$\+N\+\_\+x \textbackslash{}to \textbackslash{}infty\$), the ratio \$\textbackslash{}\+Delta z / \textbackslash{}\+Delta x\$ converges toward the continuous spatial derivative \$$|$\textbackslash{}nabla z$|$\$, maintaining an invariant physical slope regardless of raster resolution.
\end{DoxyItemize}\hypertarget{md_docs_2content_2getting__started_2core__concepts_autotoc_md117}{}\doxysubsection{\texorpdfstring{Relationship\+: talus = slope / nx}{Relationship: talus = slope / nx}}\label{md_docs_2content_2getting__started_2core__concepts_autotoc_md117}
In unit-\/box normalized domains (\$\+L\+\_\+x = 1\$), the physical cell spacing is \$\textbackslash{}\+Delta x = 1 / N\+\_\+x\$. Substituting \$\textbackslash{}\+Delta x\$ into the slope definition yields\+:

\$\$\textbackslash{}text\{slope\} = \textbackslash{}frac\{\textbackslash{}\+Delta z\}\{\textbackslash{}\+Delta x\} = \textbackslash{}frac\{\textbackslash{}text\{talus\}\}\{1 / N\+\_\+x\} = \textbackslash{}text\{talus\} \textbackslash{}cdot N\+\_\+x\$\$

Rearranging for the grid-\/cell talus threshold gives\+:

\$\$\textbackslash{}text\{talus\} = \textbackslash{}frac\{\textbackslash{}text\{slope\}\}\{N\+\_\+x\}\$\$

This identity is why erosion parameters throughout High\+Map are specified by dividing a reference slope by the grid dimension\+:
