Exports the local density map of the forest as a 2D \doxylink{classhmap_1_1Array}{Array} using 2D Kernel Density Estimation (Gaussian splatting / KDE). 

Splats each tree into the regular grid and accumulates smooth 2D Gaussian kernels with bandwidth {\ttfamily sigma}. If {\ttfamily weighted\+\_\+by\+\_\+crown} is true, each contribution is weighted by the tree crown surface (\$\textbackslash{}pi r\texorpdfstring{$^\wedge$}{\string^}2\$) instead of unit count.
