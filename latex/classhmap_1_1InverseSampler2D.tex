\doxysubsection{Detailed Description}
Sequential 2D inverse transform point sampler based on a 2D density array. 

Supports generating points one-\/by-\/one and dynamically updating density in local bounding box or index sub-\/regions \mbox{[}imin, imax\mbox{]} x \mbox{[}jmin, jmax\mbox{]}.
