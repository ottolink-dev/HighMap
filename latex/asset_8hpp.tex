\doxysubsection{Detailed Description}
Header file for 3D asset export functionalities. 

\begin{DoxyAuthor}{Author}
Otto Link (\href{mailto:otto.link.bv@gmail.com}{\texttt{ otto.\+link.\+bv@gmail.\+com}}) 
\end{DoxyAuthor}
This header declares functions and types related to exporting heightmaps as 3D mesh assets in various formats (OBJ, GLTF, PLY, STL, FBX, RAW, etc.) via Assimp and native writers.
