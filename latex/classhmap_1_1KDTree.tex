\doxysubsection{Detailed Description}
2D KD-\/\+Tree for spatial point queries. 

Supports construction from separate coordinate arrays (x, y), point vectors (std\+::vector$<$\+Point$>$), and \doxylink{classhmap_1_1Cloud}{Cloud} objects.

\begin{DoxyNote}{Note}
Input point data must remain valid for the lifetime of this \doxylink{classhmap_1_1KDTree}{KDTree} object. 
\end{DoxyNote}
