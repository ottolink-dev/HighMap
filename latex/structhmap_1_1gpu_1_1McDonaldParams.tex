\doxysubsection{Detailed Description}
Particle-\/based hydraulic erosion with flow-\/field coupling (Mc\+Donald\textquotesingle{}s model)\+: persistent per-\/cell discharge and momentum fields, exponentially filtered across iterations, couple particles through the mean local flow, producing coherent drainage networks; a bank-\/stability debris flow runs in the same solver loop against a separate sediment layer. Clean-\/room port of erosiv/soillib (LGPL-\/3, Nicholas Mc\+Donald), \href{https://github.com/erosiv/soillib}{\texttt{ https\+://github.\+com/erosiv/soillib}}. 

Parameters are physical\+: the terrain is interpreted as a world\+\_\+extent\+\_\+km x world\+\_\+extent\+\_\+km domain with height range z\+\_\+scale\+\_\+km. This makes behavior consistent across resolutions.

\begin{DoxyWarning}{Warning}
Single-\/resolution runs numerically diverge at high resolutions (\texorpdfstring{$>$}{>}= 1024\texorpdfstring{$^\wedge$}{\string^}2) beyond a few hundred steps with default parameters — use hydraulic\+\_\+mcdonald\+\_\+multiscale for high-\/resolution terrain.
\end{DoxyWarning}
Results are reproducible up to atomic scheduling order (particles read fields that other particles concurrently modify via atomic adds — a property shared with the reference implementation).
