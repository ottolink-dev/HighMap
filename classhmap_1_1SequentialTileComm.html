Detailed Description

Communicator for single-threaded sequential tile traversal. Supports cooperative fiber suspension (Option A2) so iterative collective calls (sync_overlap_buffers, all_reduce, all_union, barrier) synchronize across all tiles using a disk-backed temporary VirtualArray (VA_DISK_LRU_STREAM).
